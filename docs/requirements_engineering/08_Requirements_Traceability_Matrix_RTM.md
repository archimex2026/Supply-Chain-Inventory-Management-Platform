# Requirements Traceability Matrix (RTM)

This matrix ensures that every business requirement defined in the BRD is traced to a functional requirement in the SRS, a specific UML Use Case, and a test case.

| BR ID | Business Requirement Description | SRS ID (Functional) | UML Use Case ID | Status |
| :--- | :--- | :--- | :--- | :--- |
| **BR-01** | Real-time visibility into inventory levels | FR-IM-01 | UC5: View Inventory Levels | In Progress |
| **BR-02** | Automate PO approval workflow (> $10k) | FR-PR-02 | UC4: Approve Purchase Order | In Progress |
| **BR-03** | Track shipments from dispatch to delivery | FR-SH-01 | UC9: Track Delivery | Planned |
| **BR-04** | Centralized repository of supplier metrics | FR-SM-01, FR-SM-02 | UC1: Register Supplier, UC2: Evaluate | Planned |
| **BR-05** | Generate daily operational KPIs | NFR-PER-01 | UC10: View KPI Dashboards | In Progress |

*Note: This matrix should be updated throughout the project lifecycle, especially when requirements change.*
