# RACI Matrix (Responsibility Assignment)

This matrix defines the roles and responsibilities for key deliverables and processes within the project lifecycle.

**R = Responsible** (Does the work)
**A = Accountable** (Signs off on the work)
**C = Consulted** (Provides input)
**I = Informed** (Kept in the loop)

| Deliverable / Activity | Business Analyst | Project Sponsor | Procurement Mgr | Warehouse Mgr | IT Lead |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Project Charter** | R | A | C | C | I |
| **Business Requirements (BRD)**| R | A | C | C | I |
| **Software Requirements (SRS)**| R | A | C | C | C |
| **BPMN TO-BE Processes** | R | A | C | C | I |
| **UML Diagrams (System Design)**| R | I | I | I | A |
| **Data Dictionary & ERD** | R | I | I | I | A |
| **User Acceptance Testing (UAT)**| C | I | R | R | C |
| **Go-Live Approval** | C | A | I | I | R |
