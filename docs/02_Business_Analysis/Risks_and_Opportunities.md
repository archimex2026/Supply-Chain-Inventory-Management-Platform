# Risks & Opportunities

## Risks
- **Risk 1:** Warehouse staff resist adopting mobile scanners. (Mitigation: Comprehensive training and UI simplification).
- **Risk 2:** Legacy supplier data is corrupt. (Mitigation: Data cleansing sprint prior to Go-Live).

## Opportunities
- **Opp 1:** Use historical data to implement ML-based demand forecasting in Phase 2.
- **Opp 2:** Provide a vendor portal so suppliers can update their own data.
