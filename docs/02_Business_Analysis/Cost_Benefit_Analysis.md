# Cost-Benefit Analysis (CBA)

## 1. Executive Summary
This document provides a financial and qualitative justification for the Supply Chain & Inventory Management Platform. It compares the expected costs of development, implementation, and maintenance against the anticipated financial benefits derived from operational efficiencies and error reduction.

## 2. Estimated Costs (Year 1)

| Cost Category | Description | Estimated Amount ($) |
| :--- | :--- | :--- |
| **Software Development** | Platform architecture, backend, frontend development (Internal Team + Contractors) | $120,000 |
| **Infrastructure** | Cloud hosting (AWS/Azure), database licensing, CDN services | $15,000 |
| **Training & Onboarding**| Training sessions for Warehouse and Procurement teams | $8,000 |
| **Maintenance & Support**| Ongoing bug fixes, SLA support (Annual) | $20,000 |
| **Total Initial Investment**| | **$163,000** |

## 3. Anticipated Benefits (Year 1)

| Benefit Category | Description | Estimated Savings ($) |
| :--- | :--- | :--- |
| **Reduced Inventory Shrinkage**| Real-time tracking and cycle counting reduces lost or unaccounted stock by 40%. | $50,000 |
| **Procurement Efficiency** | Automation of PR/PO generation saves approx. 20 hours/week per officer. | $35,000 |
| **Optimized Warehouse Labor** | Streamlined picking routes and directed put-away reduces overtime. | $40,000 |
| **Penalty Avoidance** | Better shipment tracking reduces SLA breach penalties from customers. | $25,000 |
| **Total Annual Benefit** | | **$150,000** |

## 4. Return on Investment (ROI) & Payback Period
- **Net Present Value (NPV) over 3 years:** Positive (Assuming 5% discount rate)
- **Payback Period:** ~13 months
- **3-Year ROI:** 176% 

## 5. Intangible Benefits
- Increased employee satisfaction due to modern tooling.
- Better supplier relationships due to transparent communication and timely PO processing.
- Enhanced decision-making capacity for executive management via real-time KPIs.
