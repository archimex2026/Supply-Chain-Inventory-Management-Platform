# Functional Requirements (FR)

- **FR-SM-01:** System allows C.R.U.D. operations on Supplier profiles.
- **FR-PR-01:** Auto-generate Draft PR when stock drops below Reorder Point.
- **FR-IM-01:** Real-time stock update (Quantity On Hand) upon Goods Receipt.
- **FR-WH-01:** System maps physical bins to logical locations.
